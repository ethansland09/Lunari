HOW IT WORKS

1. Type an English message.
2. Lunari converts it to scrambled letters.
3. The letters are displayed upside down.
4. Write the upside-down Lunari.
5. Scan it with the camera.
6. The scanner tries multiple orientations, image filters and OCR settings.
7. The best result is automatically decoded.
